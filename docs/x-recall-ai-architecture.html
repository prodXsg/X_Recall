X X RECALL

AI Architecture

X Recall uses lightweight AI pipelines to classify, embed, and retrieve user-consumed content in real time, enabling contextual recall without disrupting feed behavior.

View live prototype GitHub repo

Overview

The system captures user interactions such as scroll pauses, likes, and clicks, then processes content through classification and embedding models to create a structured memory layer.

Core Components

A classification model categorizes content into topics, while embeddings enable semantic search. A retrieval layer matches user queries or intent with previously seen content.

Feedback Loop

User corrections improve model accuracy over time by reinforcing relevant classifications and reducing noise, creating a continuously improving recall system.

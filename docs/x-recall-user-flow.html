X X RECALL

User Flow

X Recall enables users to instantly find and revisit previously seen content without relying on memory, bookmarks, or manual search.

View live prototype GitHub repo

Trigger

The user remembers seeing a tweet or piece of content earlier but cannot find it again through traditional scrolling or search.

Entry Point

The user accesses X Recall through a dedicated entry point within the app, such as a search bar or recall button integrated into the interface.

Query / Intent

The user describes what they remember in natural language, such as keywords, topics, or partial context, instead of exact matches.

Processing

The system interprets the query, matches it against previously seen content using semantic understanding, and retrieves relevant results.

Results

The user is shown a ranked list of relevant past content, allowing them to quickly identify and access what they were looking for.

Feedback Loop

The system improves over time by learning from user interactions, such as clicks or refinements, enhancing future recall accuracy.
